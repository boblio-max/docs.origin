v1.7.15 Stable Now Live

The latest release adds typed parameters and typed class fields, type-aware casts on builtin arguments, auto-inference for untyped declarations, a range step argument, and stricter const immutability. Origin is designed to be the ultimate bridge between software logic and hardware execution.

• Typed Parameters: Annotate function and method parameters (def add(a: int, b: int)) and class fields (class Point(x: int, y: int)) for strict, self-documenting code.

• Typed Loops & Conditions: Typed loop variables (for i: int in range(0, 10)) and optional condition casts (if (cond): bool).

• Builtin Arg Casts: Type-aware casts on builtin calls (len(x: str), sqrt(x: float), rand_num(1: int, 100: int), range(0: int, 10: int, 2: int)).

• Auto-Inference: let/const without a type annotation infer the type automatically, with a friendly warning nudging you toward strict typing.

• Range Step: range(start, end, step) supports an optional third argument.

• Const Safety: Reassigning a const is now rejected with a clear error in both the VM and interpreter.

• Rebuilt Installer (July 2026): The Windows binary has been rebuilt from the v1.7.15 reference sources with the flat-layout imports normalized, so the released origin.exe no longer depends on the in-progress bytecode VM packages.

• Cross-Platform Builds: Native installers are now produced for Windows (x64), macOS (universal: Apple Silicon + Intel), and Linux (x64 + Raspberry Pi). A new GitHub Actions matrix builds each platform's bundle with per-binary SHA256SUMS verification.

• Coming Next (v1.8): A dedicated bytecode compiler and VM (runnerByte.py) is in active development on the origin-dev branch — it will replace the AST-to-Python interpreter behind the scenes while keeping the Origin surface stable.
