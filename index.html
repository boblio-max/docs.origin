v1.7.20 Stable Now Live

The v1.7.20 release adds a GUI automation library and a run command shell construct, plus bytecode VM stability fixes. It builds on the v1.7.19 additions of multi-assignment declarations (let a, b = 1, 2) with per-name type annotations, stricter type checking on let across both the interpreter and the bytecode VM, __file__ support for library imports, and an expanded HuggingFace-style transformer library. Origin is designed to be the ultimate bridge between software logic and hardware execution.

• GUI Automation (New in v1.7.20): import gui — a GUI class wrapping pyautogui for mouse control (moveTo, click, dragTo, scroll), keyboard (typewrite, press, hotkey), screenshots (screenshot, pixel, locateOnScreen), and dialogs (alert, confirm, prompt) via lazy imports. Module-level helpers guiMoveTo, guiClick, guiTypewrite also available.

• Run Command (New in v1.7.20): run command "echo hello" executes shell commands via subprocess.run — use it for system automation and tooling. Supports a trailing block for flags (run command "ls" { }).

• VM Reliability (v1.7.20): Bytecode VM now isolates parallel threads with per-thread VMs and merges variables safely, handles 0xFF as -1 for file reads, fixes HARDWARE_CALL constant lookup, and improves compiler emit to accept multiple operands.

• Multi-Assignment (v1.7.19): Declare several variables at once — let a, b = 1, 2 — with per-name type annotations (let p, q: int, str = 6, "hi") checked in both the interpreter and the bytecode VM.

• Stricter Type Checking: let declarations are now type-checked consistently across all three backends (interpreter, VM, and compiler).

• __file__ Support: Library imports can resolve relative to the running script, so bundled libraries work inside the pip package and standalone binary.

• Expanded Transformer Library: The built-in HuggingFace-style transformer library now ships device selection, tokenization, text generation, model evaluation, LoRA adapters, and a one-shot run_pipeline fine-tuner.

• Floor / Ceil: New built-in floor and ceil keyword functions (print floor(3.7) → 3, print ceil(3.2) → 4).

• Floor Division: The // operator performs integer floor division in both the VM and interpreter (print 7 // 2 → 3).

• Skip Alias: skip now works as an alias for continue inside loops.

• Better Syntax Errors: Parse failures now report the exact line and column with a caret pointer and a helpful suggestion instead of a bare message.

• Pi & Abs: The pi constant and abs keyword function from v1.7.16 (print pi → 3.141592653589793).

• Auto-Inference: let/const without a type annotation infer the type automatically, with a friendly warning nudging you toward strict typing.

• Cross-Platform Builds: Native installers are produced for Windows (x64), macOS (universal), and Linux (x64 + Raspberry Pi) with per-binary SHA256SUMS verification.

• Coming Next (v1.8): A dedicated bytecode compiler and VM (runnerByte.py) is in active development on the origin-dev branch — it will replace the AST-to-Python interpreter behind the scenes while keeping the Origin surface stable.
