v1.7.21 Stable STABLE

GUI automation + run command + VM hardening — built on v1.7.19 multi-assign and typed let. The ultimate bridge between software logic and hardware execution.

Run Command — run command "echo hello" via subprocess.run.
VM Reliability — isolated parallel VMs, 0xFF→-1, HARDWARE_CALL fix.
Also: let a, b = 1, 2 per-name types, floor/ceil, //, skip, caret errors, pi/abs.
