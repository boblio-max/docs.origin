Frequently Asked Questions

Install via pip: pip install origin-or. On Raspberry Pi: pip install origin-or[pi].

Origin runs on Windows, macOS, Linux, and Raspberry Pi ARM. The bytecode VM is included in the pip package.

Use set servo.angle 1, 90 to set a servo to 90 degrees. Clamping is enforced at 0–180° at compile time.

The VM compiles AST → stack bytecode and executes it (default, faster, type-checked). The interpreter transpiles to Python source and execs it (fallback, debugging).
