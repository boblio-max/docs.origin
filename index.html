v1.7.18 Stable Now Live

The latest release adds built-in floor and ceil keyword functions, floor division (//), a skip alias for continue, and precise syntax-error diagnostics with line/column caret reporting. The v1.7.16 additions of a pi constant and abs keyword function continue to work as before. Origin is designed to be the ultimate bridge between software logic and hardware execution.

• Floor / Ceil: New built-in floor and ceil keyword functions (print floor(3.7) → 3, print ceil(3.2) → 4).

• Floor Division: The // operator performs integer floor division in both the VM and interpreter (print 7 // 2 → 3).

• Skip Alias: skip now works as an alias for continue inside loops.

• Better Syntax Errors: Parse failures now report the exact line and column with a caret pointer and a helpful suggestion instead of a bare message.

• Pi & Abs: The pi constant and abs keyword function from v1.7.16 (print pi → 3.141592653589793).

• Typed Parameters: Annotate function and method parameters (def add(a: int, b: int)) and class fields (class Point(x: int, y: int)) for strict, self-documenting code.

• Typed Loops & Conditions: Typed loop variables (for i: int in range(0, 10)) and optional condition casts (if (cond): bool).

• Auto-Inference: let/const without a type annotation infer the type automatically, with a friendly warning nudging you toward strict typing.

• Range Step: range(start, end, step) supports an optional third argument.

• Const Safety: Reassigning a const is now rejected with a clear error in both the VM and interpreter.

• Rebuilt Installer (August 2026): The Windows binary has been rebuilt from the v1.7.18 reference sources with the flat-layout imports normalized, so the released origin.exe no longer depends on the in-progress bytecode VM packages.

• Cross-Platform Builds: Native installers are now produced for Windows (x64), macOS (universal: Apple Silicon + Intel), and Linux (x64 + Raspberry Pi). A new GitHub Actions matrix builds each platform's bundle with per-binary SHA256SUMS verification.

• Coming Next (v1.8): A dedicated bytecode compiler and VM (runnerByte.py) is in active development on the origin-dev branch — it will replace the AST-to-Python interpreter behind the scenes while keeping the Origin surface stable.
