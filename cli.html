Origin CLI

The modern command-line interface for Origin.
Install in one command. Start building in seconds.

Install Origin CLI
curl -fsSL https://docs-origin.onrender.com/cliinstall.sh | sh

Works on macOS, Linux, and Windows. Requires sh (Unix) or PowerShell (Windows).

Windows (PowerShell): irm https://docs-origin.onrender.com/cliinstall.ps1 | iex

Features Why CLI?

Everything you need

⚡

Instant Install

One command. No Python, no pip, no package managers. Just curl and go.

🔧

Project Scaffolding

Create new Origin projects with origin create. Folder structure generated instantly.

▶️

Run Anything

Execute .or, .py, and .java files from one interface.

🔄

Auto-Update

Keep your CLI current with origin update cli. Always on the latest version.

🎯

REPL Mode

Interactive session for testing code snippets. Just type origin to start.

🩺

Doctor Checks

Diagnose issues with origin doctor. Verifies dependencies and environment.

Why use the CLI?

Method Requires Python Cross-Platform Standalone Best For
CLI (curl install) No Yes Yes Quick setup, any machine
pip install Yes (3.10+) Yes No Python projects, Raspberry Pi
Standalone binary No Yes Yes Manual download, air-gapped

Commands

$ origin help
Available commands:
origin help - Show this help message
origin clear - Clear the console
origin exit - Exit the CLI
origin <file>.or - Run an Origin file
origin <file>.py - Run a Python file
origin <file>.java - Compile and run a Java file
origin c <file>.java - Compile a Java file
origin create <structure>.otxt <location> - Generate folder structure

Get started

Install now
curl -fsSL https://docs-origin.onrender.com/cliinstall.sh | sh

Then run origin to start the interactive CLI.
