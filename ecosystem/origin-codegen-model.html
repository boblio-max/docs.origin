Origin Codegen Model

An AI model that generates Origin code from natural language instructions.

🧠

What It Does

Type a plain-English instruction like "Print the product of 2093 and 2516" and the model generates valid Origin code: print 2093 * 2516.

⚡

How It Works

Built on Qwen2.5-1.5B, fine-tuned with LoRA on a curated dataset of Origin instruction-output pairs. Trained for 3 epochs with AdamW optimization.

🚀

Get Started

Clone the repo, install dependencies, and run training or inference in minutes.

View on GitHub

Quick Start

Install Dependencies

$ python -m venv .venv
$ .venv\Scripts\activate
$ pip install torch transformers peft accelerate

Train the Model

$ python train.py
Epoch 1 loss: 1.234
Epoch 2 loss: 0.567
Epoch 3 loss: 0.234

Run Inference

$ python origin-codegen.py
> Print the sum of 100 and 200
print 100 + 200

Architecture

Base Model: Qwen2.5-1.5B (1.5B parameters)

Fine-Tuning: LoRA (Low-Rank Adaptation)

Rank: 8, Alpha: 16

Target Modules: q_proj, v_proj

Training Data: 1,800 instruction-output pairs

Epochs: 3

Optimizer: AdamW (lr=2e-4)
