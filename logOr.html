v1.7.20 Stable Now Live

The v1.7.20 release adds a GUI automation library and a run command shell construct, plus bytecode VM stability fixes. It builds on the v1.7.19 additions of multi-assignment declarations (let a, b = 1, 2), __file__ support, and the expanded transformer library. Origin is designed to be the ultimate bridge between software logic and hardware execution.

• GUI Automation (New in v1.7.20): import gui — a GUI class wrapping pyautogui for mouse, keyboard, screenshot and dialogs (moveTo, click, typewrite, screenshot, alert and more).

• Run Command (New in v1.7.20): run command "echo hello" executes shell commands via subprocess.run for system automation.

• VM Reliability (v1.7.20): Isolated parallel threads, 0xFF read fix, and hardware-call constant handling.

• Multi-Assignment (v1.7.19): Declare several variables at once — let a, b = 1, 2 — with per-name type annotations (let p, q: int, str = 6, "hi") checked in both the interpreter and the bytecode VM.

• Stricter Type Checking: let declarations are now type-checked consistently across all three backends (interpreter, VM, and compiler).

• __file__ Support: Library imports can resolve relative to the running script, so bundled libraries work inside the pip package and standalone binary.

• Expanded Transformer Library: The built-in HuggingFace-style transformer library now ships device selection, tokenization, text generation, model evaluation, LoRA adapters, and a one-shot run_pipeline fine-tuner.
