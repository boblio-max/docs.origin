v1.7.16 Stable Now Live

The latest release adds a built-in pi constant and abs keyword function, alongside the v1.7.15 additions of typed parameters, typed class fields, type-aware casts on builtin arguments, auto-inference for untyped declarations, a range step argument, and stricter const immutability. Origin is designed to be the ultimate bridge between software logic and hardware execution.

• Typed Parameters: Annotate function and method parameters (def add(a: int, b: int)) and class fields (class Point(x: int, y: int)).

• Typed Loops & Conditions: Typed loop variables (for i: int in range(0, 10)) and optional condition casts (if (cond): bool).

• Builtin Arg Casts: Type-aware casts on builtin calls (len(x: str), sqrt(x: float), rand_num(1: int, 100: int), range(0: int, 10: int, 2: int)).

• Auto-Inference: Untyped let/const infer their type automatically with a warning nudge.

• Range Step: range(start, end, step) supports an optional third argument.

• Const Safety: Reassigning a const is now rejected in both the VM and interpreter.
