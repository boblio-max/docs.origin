v1.7.18 Stable Now Live

The latest release adds built-in floor and ceil keyword functions, floor division (//), a skip alias for continue, and precise syntax-error diagnostics with line/column caret reporting. Origin is designed to be the ultimate bridge between software logic and hardware execution.

• Floor / Ceil: New built-in floor and ceil keyword functions (print floor(3.7) → 3, print ceil(3.2) → 4).

• Floor Division: The // operator performs integer floor division (print 7 // 2 → 3).

• Skip Alias: skip now works as an alias for continue inside loops.

• Better Syntax Errors: Parse failures report the exact line and column with a caret pointer and a helpful suggestion.
