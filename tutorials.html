Getting Started with Origin

Learn the basics of the Origin programming language, from installation to writing your first program.

>

- Download Origin from Github

- Set up your development environment (Python 3.x)

- Write your first Origin Program using the documentation

- Save file as file.or

- To use the new bytecode compiler:

- In runnerByte.py, set code file to your saved file

- Run python ORIGIN_CODE/runnerByte.py

- See the results in your terminal!

>

Advanced Origin Techniques

Dive deeper into Origin with tutorials on advanced topics and best practices.

>

File I/O

- Learn how to read and write files using the open statement.

- Syntax: open "data.txt" "w" as f

>

Object-Oriented Programming

- Organize your code with classes and methods.

- Syntax: class Robot(name) { def greet() { print "Hello" } }

>

Symbolic Logic

- Use &&, ||, and ! for complex conditions.

>

Python Interoperability

- Use py { ... } blocks to run native Python code.

>

Modern Hardware Syntax

- For servos: set servo.angle 1, 90

- For GPIO: set pin 12, 1

>

Error Handling

- Wrap risky code in try { ... } except { ... }.

- Use else for code that runs only on success.

>

Parallel Processing

- Use parallel (4) { ... } to span logic across 4 CPU threads.
