Documentation

Complete reference for the Origin programming language.

Variables & Data

Variables in Origin are block-scoped and declared with the let keyword. All declarations must include an explicit type annotation.

let   x: int    = 10         # typed declaration
let   name: str = "Origin"
let   flag: bool   = true       # boolean type (lowercase)
const pi: float = 3.14159    # immutable reference

Data Structures

Origin supports native lists, dictionaries, and tuples for complex data management.

# Lists
let my_list: list = [1, 2, 3]
print my_list[0]            # indexing starts at 0

# Dictionaries
let my_dict: dict = {"a": 1, "b": 2}
print my_dict{"a"}           # dictionary access uses { }

Hardware Control

Low-level hardware interaction is handled through the global set namespace. Origin provides first-class support for Raspberry Pi GPIO and ServoKit (PCA9685).

# Modern dot-notation
set servo.angle 1, 90       # Set servo 1 to 90 degrees
set pin 12, 1               # BCM pin 12 Output High

# Clamping example
set servo.angle 0, 250      # Automatically clamped to 180

Module System

The import statement in Origin currently functions as a Header Inclusion mechanism.

import more_logic           # Prepends more_logic.or to this file
from math import sqrt       # Direct inclusion from standard libraries

let x: float = sqrt(16)

Raw Python Blocks

Embed raw Python code directly into Origin scripts using the py { ... } syntax.

py {
    import math
    for i in range(5):
        print("Python depth:", math.sin(i))
}

Error Handling

Origin provides a robust mechanism for catching and handling runtime exceptions using try, except, and else blocks.

try {
    # Attempt a hardware command
    set servo.angle 15, 45
} except {
    print "Hardware error caught!"
} else {
    print "Command successful."
}
