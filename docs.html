Language Reference

Origin Documentation

Complete reference for the Origin programming language — hardware-first, expressive, and built for control.

v1.5 v1.7 v1.7.5 — Bytecode Stable

Variables & Data

Variables in Origin are block-scoped and declared with the let keyword. All declarations must include an explicit type annotation — the compiler enforces strict typing and immutability (for const) at runtime.

declaration.org origin 
let   x: int    = 10         # typed declaration
let   name: str = "Origin"
let   flag: bool   = true       # boolean type (lowercase)
const pi: float = 3.14159    # immutable reference
let empty = none             # none literal
INFO Origin enforces strict typing. Use lowercase true, false, and none for literals. Reassigning a const at runtime will raise a RuntimeError.

Data Structures

Origin supports native lists, dictionaries, and tuples for complex data management.

data.org origin 
# Lists
let my_list: list = [1, 2, 3]
print my_list[0]            # indexing starts at 0

# Dictionaries
let my_dict: dict = {"a": 1, "b": 2}
print my_dict{"a"}           # dictionary access uses { }

# Tuples
let my_tuple: tuple = (10, 20, 30)
print my_tuple[1]

print len(my_list)           # returns collection length

Control Flow

Origin uses indentation to denote block scope — no braces required. Standard control structures include if / elif / else, while, and for range loops.

control.org origin 
# Conditional
if x > 100 {
    print "high"
} elif x > 50 {
    print "mid"
} else {
    print "low"
}

# Loops with break and continue
for i in range(0, 10) {
    if i == 5 { break }
    print i
}

while true {
    pass        # do nothing
    break
}

# Range loops
for i in range(0, 100) {
    print i
}

Functions

Functions are defined with the def keyword. They are first-class values and can be passed as arguments. Return values are indicated with return.

functions.org origin 
def add(a, b) {
    return a + b
}

def greet(name) {
    print "Hello, " + name
}

let result: int = add(4, 7)    # → 11
greet("world")              # → Hello, world

Hardware Control

Low-level hardware interaction is handled through the global set namespace. Origin provides first-class support for Raspberry Pi GPIO and ServoKit (PCA9685) devices.

hardware_modern.org origin 
# Modern dot-notation (recommended)
set servo.angle 1, 180      # Auto-clamped 0-180

# Direct GPIO control
set pin 12, 1               # BCM pin 12 High (Output mode auto-configured)

# Classic syntax (still supported)
set servo[0] = angle, 90
Command Parameters Description
set servo.angle index, val (index: int, val: int/float) Moves servo at index to specified angle. Auto-clamped: 0–180°.
set pin num, state (num: int, state: 0/1) Drives BCM pin to state (1: High, 0: Low). Initializes GPIO BCM mode.
SAFETY Origin includes automatic hardware safety clamping. If a servo angle outside [0, 180] is sent, the interpreter clamps it to the nearest bound and issues a console warning to prevent physical gear damage.

Input / Output

Standard output is written with print. User input can be read from stdin using input(), which always returns a string — cast explicitly if a numeric value is needed.

io_example.org origin 
print "Enter a number:"
let val: str = input("> ")
let x: int   = int(val)     # explicit cast
print x

Module System

New in v1.5

Version 1.5 introduced a first-class module system for standard library access and cross-file code reuse. Import an entire namespace or pull named exports directly.

math_example.org origin 
import math
import random

print math.sqrt 16           # → 4.0
print math.pow  2, 8         # → 256.0
print random.randint(1, 10)    # → random integer

# Named import — drops the namespace prefix
from math import sqrt, floor

print sqrt  25               # → 5.0
print floor 3.7              # → 3
INFO Module resolution searches the working directory first, then the standard library path. Third-party packages are not yet supported in v1.5.

File I/O

New in v1.7

Read from and write to standard files directly using the open statement. File modes include "r", "w", "a", etc. mapping straight to python built-ins via the compiler layer.

files.org origin 
open "data.txt" "w" as f
# further write operations ...

Object-Oriented Programming

New in v1.7

Origin now includes a structured class keyword. Classes bundle fields natively, offering methods inside class blocks directly executed as blocks mapping methods internally.

class_example.org origin 
class Robot(name, id) {
    def identify() {
        print "I am a robot"
    }
}

Concurrency

New in v1.7

Perform multi-processor parallel tasks syntactically using the parallel block to scale computations across system threads dynamically natively.

parallel.org origin 
parallel (4) {
    # Task runs across 4 threads
    print "Working concurrently"
}

Error Handling

New in v1.7.5

Origin uses try / except / else blocks for robust error management. Errors are mapped from the underlying environment and can be caught to prevent script termination.

error_handling.org origin 
try {
    const x: int = 10
    x = 20                    # Raises RuntimeError
} except {
    print "Caught constant re-assignment"
} else {
    print "No errors occurred"
}
Error Type Common Trigger
TypeError Type mismatch in let assignment or function call.
RuntimeError Illegal state (e.g., constant re-assignment).
ImportError Module not found or failed hardware initialization.

Math & System Execution

New in v1.7

Origin provides high-performance mathematical built-ins and inline code execution pipelines. Important: Built-ins like sqrt and rand_num are evaluated at runtime, enabling dynamic logic within loops and conditions.

math_sys.org origin 
let x: float = sqrt(25)               # → math.sqrt(25.0) at runtime
let rnd: int = rand_num(1, 10)      # → different result each call
let sz: int  = len([1, 2, 3])       # → collection length

exec "print('hello from subprocess')"

Raw Python Integration

New in v1.7.5

For advanced use cases requiring features not yet native to Origin, you can embed raw Python code directly using the py block syntax. This code is executed natively in the underlying Python environment.

python_interop.org origin 
py {
    # Raw Python code block
    import math
    for i in range(5):
        print("Python-native sqrt:", math.sqrt(i))
}
IMPORTANT Variables declared inside a py block may not be visible to the Origin type-checker. Use this feature sparingly for library integrations only.

Operators & Logic

Origin supports symbolic and word-based logic, bitwise operations, and compound assignments.

ops.org origin 
# Compound Assignments
x += 1
y *= 10
mask &= 0b1111

# Unary Operators
counter++
index--

# Logical Operators (Symbolic or Semantic)
if (a > 0 && b < 100) || !is_locked { ... }
if (a > 0 and b < 100) or not is_locked { ... }

# Comparison
if x === y { # Exact match }
if a <> b { # Legacy not-equal }

Generators

Functions can yield values to create simple generators.

yield.org origin 
def counter() {
    yield 1
    yield 2
}
