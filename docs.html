🦚 Origin v1.7.30 · Stable

Documentation

Complete reference for the Origin programming language v1.7.30 — hardware-first, Python-native, with a bytecode VM by default.

v1.7.30 update: adds the open "file", "mode" as f statement (new OPEN_FILE opcode; path/mode accept f-strings) and a dialect guard so template mappings no longer hijack keyword-led lines. See Input / Output. v1.7.29 shipped two dialect shorthands by default — "let $n:int = $v" _ "$n:$v" and "print $n" _ "p $n". v1.7.28 introduced dialect support and the modular package layout (lexer / parser / interpreter / classes subpackages) with the bytecode VM as the default backend (origin app.or) and the AST interpreter on origin i app.or.

Getting Started

Install Origin, write a .or file, run it. Three paths:

Option A — pip (Windows, macOS, Linux, Raspberry Pi)

pip install origin-or
origin --version   # Origin Programming Language v1.7.30

Option B — Windows installer

Expand-Archive .\OriginInstallerV1.7.30.zip
cd OriginInstallerV1.7.30
.\secure_install.ps1
origin --version

Option C — Raspberry Pi one-liner

curl -sSL https://origin.dev/install.sh | bash

Hello, Origin

# helloworld.or
let name: str = "Origin"
print "Hello, " + name + "!"
origin helloworld.or
# Output: Hello, Origin!

Statements are newline-separated. Blocks use curly braces { }. Keywords are lowercase (let, if, for, print).

Running Programs

origin hello.or        # bytecode VM (default — use this)
origin i hello.or      # AST-to-Python interpreter (fallback)

The VM compiles your program to stack bytecode and executes it. The interpreter transpiles to Python source and execs it. Output is identical for core language features. Two exceptions:

  • Dialects only expand on the VM path. Interpreter mode skips dialect lines (see Dialects).
  • The standalone origin.exe ships without the VM package and falls back to the interpreter automatically.

Backends: VM vs Interpreter

BackendCommandHow it worksUse when
VMorigin app.orCompiles AST → stack bytecode (bc/to_byte.py), runs on bc/svm.pyDefault. Faster, type-checked, dialect-aware.
Interpreterorigin i app.orGenerates Python source per node, execs itDebugging codegen, exe fallback, py { } inspection.

Type checking on the VM is strict at declaration: let x: int = "hi" is a compile-time error, while the interpreter may defer it. Prefer the VM and treat origin i output as a diagnostic view, not a second semantics.

Data Types

Five core types, named in let/const annotations as int, float, str, bool, plus list, dict, and any where the checker permits. Annotations are optional — omitting them infers the type.

Integers

let x: int = 42
let addr: int = 0x48      # hex literal → 72
let negative: int = -10

Floats

let e: float = 2.71828
let temp: float = 98.6

Strings

Double or single quotes. Escapes \", \', \n work. Prefix f for f-strings with {expr} interpolation.

let name: str = "Origin"
let msg: str = 'Hello World'
let escaped: str = "He said \"hi\""
let label = f"servo {1 + 1} ready"

Booleans

let active: bool = true
let done: bool = false

None

let empty = none

Variables & Constants

# Variable with type annotation
let x: int = 10
let name: str = "Origin"
let flag: bool = true

# Variable without type (inferred)
let count = 0

# Multi-assignment with per-name types
let a, b = 1, 2
let m: int, n: str = 1, "one"

# Constants — immutable after assignment
const PI: float = 3.14159
const VERSION: str = "1.7.30"
const MAX_SERVOS: int = 6

# Reassignment
x = 20          # OK
# PI = 3.0      # ERROR: Cannot reassign constant

Compound Assignment

let score: int = 100
score += 10    # 110
score -= 5     # 105
score *= 2     # 210
score /= 7     # 30
score %= 4     # 2
score //= 2
score **= 2

Increment / Decrement

x++   # x = x + 1
x--   # x = x - 1

Operators

Arithmetic

let a = 10 + 3     # 13
let b = 10 - 3     # 7
let c = 10 * 3     # 30
let d = 10 / 3     # 3.33 (division)
let e = 10 // 3    # 3   (floor division)
let f = 10 % 3     # 1   (modulo)
let g = 2 ** 8     # 256 (exponentiation)

Comparison

x == y     # equal
x != y     # not equal
x < y      # less than
x > y      # greater than
x <= y     # less or equal
x >= y     # greater or equal

Logical

# Word-style
if x > 0 and y > 0 { ... }
if x > 0 or y > 0 { ... }
if not done { ... }

# Symbol-style (also valid)
if x > 0 && y > 0 { ... }
if x > 0 || y > 0 { ... }
if !done { ... }

Unary

let neg = -x       # negation

Smart String Concatenation

+ auto-converts when either side is a string. No manual casting.

let age: int = 17
print "I am " + age + " years old"
# Output: I am 17 years old

Precedence (high → low)

Unary - ! not → ** → * / // % → + - → comparisons → && → || → and → or → ??. When in doubt, parenthesize.

Null Coalescing

?? yields the left side unless it is none, otherwise the right side. Ideal for defaults from sensors, dicts, or user input.

let nick = none
print nick ?? "anonymous"   # anonymous

let reading = sensor_val ?? -1
print reading

If / Elif / Else

if temp > 100 {

For Loops

    print i

Break, Continue, Skip

while true {
    if done { break }        # exit the loop entirely

Functions

Define with def (func is an alias). Curly-brace bodies, parameters, return values.

def greet(name) {
    print "Hello, " + name + "!"
}

func welcome(name) {
    print "Welcome, " + name
}

greet("Origin")

Return Values

def add(a, b) {
    return a + b
}

let result = add(10, 20)
print result    # 30

Typed Parameters

def add(a: int, b: int) {
    return a + b
}

print add(2, 3)            # 5
print add(2: int, 3: int)  # casts on call arguments work too

Recursion

def factorial(n) {
    if n <= 1 {
        return 1
    }
    return n * factorial(n - 1)
}

print factorial(5)    # 120

Multi-line Signatures & Calls

    z

Classes

Constructor fields in parentheses (with optional :type), methods take self, attribute access via dots.

class Point(x: int, y: int) {
    def scale(self, factor: float) {
        self.x = self.x * factor
        self.y = self.y * factor
    }

    def show(self, label) {
        print label
        print self.x
        print self.y
    }
}

let p = Point(3, 4)
p.scale(2.0)
p.show("Point:")

Attribute Access

print p.x     # read
p.x = 999     # write
print obj.nested.value   # chained access

Scope Management

Lexical scoping. let inside a function is local. Use global to modify an outer variable.

let x = 10

def local_test() {
    let x = 20
    print x             # 20
}

def global_test() {
    global x
    x = 30
}

local_test()
print x                 # still 10

global_test()
print x                 # now 30

Constant Isolation

const y = "Global Constant"

def test_const() {
    const y = 100
    print y             # 100
}

test_const()
print y                 # "Global Constant"

Input / Output

Print

print is a statement — no parentheses. Takes a single expression.

print "Hello, World!"
print 42
print "Result: " + result

Write

write emits without a trailing newline (useful for progress output).

write "warming up… "
print "done"

Input

let name: str = input "What is your name? "
print "Hello, " + name

let age: int = int(input "Enter your age: ")

Read

read loads a file's contents as a string.

let body: str = read "notes.txt"
print body

Open … as

open opens a file and binds the handle to a variable. Path and mode accept plain strings, f-strings, and variables. Works on the VM and the interpreter.

open "notes.txt", "r" as f
open f"logs/{code_name}.txt", "w" as g

Math

let root = sqrt(16.0)          # 4.0
let r = rand_num(1, 100)       # random int 1..100
let a = abs(-5)                # 5
let f = floor(3.7)             # 3

Collections

let items = [1, 2, 3, 4, 5]

Type Casting

let s: str = "123"
let n: int = int(s)            # 123
let x: int = 42
let text: str = str(x)         # "42"

Range

range(start, end) yields start (inclusive) to end (exclusive). Optional third argument is step.

for i in range(0, 5) {
    print i
}
# 0 1 2 3 4

for i in range(0, 10, 2) {
    print i
}
# 0 2 4 6 8

for i: int in range(0, 5) {
    print i
}

let count: int = 10
for i in range(0, count) {
    print "Step " + i
}

Parallel Execution

The parallel block runs statements on threads and joins them before continuing. On the VM each thread gets an isolated VM.

Auto-parallel

parallel {
    step(0)    # thread 1
    step(1)    # thread 2
}
# Both threads joined before continuing

Fixed Thread Count

parallel (4) {
    print "Worker running"
    process_data()
}
# 4 threads, each running the full block

Dialects (TOML)

Dialects let foreign-language lines live inside .or programs. Each source line is matched against the bundled origin.toml table and compiled to real Origin at runtime, on the VM path.

Mapping format

One mapping per line: "<origin source>" _ "<dialect line>" — left is compilable Origin, right is what you write. $name captures text, $$ is a literal dollar.

"let $n:int = $v" _ "$n:$v"
"print $n" _ "p $n"

Writing dialect code

x:5        # → let x:int = 5
p x        # → print x
print x + 1

Rules & limits

  • VM only. origin app.or expands dialects; origin i app.or skips dialect lines.
  • Single-line. Matching is per source line; blocks must stay core Origin.
  • Exact wins, then templates in file order. Every $name on the left must appear on the right.
  • Shipped by default. Every install bundles origin.toml; edit it to add your own shorthands.
  • Precompiled fallback. Exact mappings can be precompiled to origin_bytecode.toml via runnerTOML --gen (legacy path); templates always expand inline, sharing constants and control flow.
  • Trust. A mapping runs its origin source with full language power — same trust as py { }. Only install tables you trust.

Hardware Control

First-class robotics support. Servo angles clamp to 0–180° at the compiler — no stripped gears, no runtime guards.

Servo Control

set servo.angle 1, 90

set servo.angle 0, 250    # clamped to 180°
set servo.angle 2, -10    # clamped to 0°

GPIO Pin Control

set pin 12, 1    # BCM pin 12 HIGH
set pin 12, 0    # BCM pin 12 LOW

IMU Sensors

Native MEMS IMU support (accelerometer + gyroscope + temperature). Declare with an I²C address, then read.

Declare an IMU

let imu: mpu6050 = mpu6050 address 0x68

Read sensor data

let ax: float = accel from imu
let ay: float = accel from imu
let az: float = accel from imu

let gx: float = gyro from imu
let gy: float = gyro from imu
let gz: float = gyro from imu

let temp: float = temp from imu

Supported chips: mpu6050, mpu9250, mpu6500, mpu9255, mpu6000, mpu9150, mpu9256, mpu9257, mpu9258, mpu9259.

Hardware Protocols

Built-in I2C, SPI, and UART primitives. Native on Raspberry Pi; simulate or fail gracefully elsewhere.

I2C

let addr: int = 0x48
let reg: int = 0x01

let val: int = i2c.read(addr, reg)   # read a byte
i2c.write(0x48, 0x01, 0xFF)          # write a byte

SPI

spi.transfer([0x01, 0x02, 0x03])

UART

uart.write("Hello UART")

Raw Python Blocks

Embed Python verbatim with py { }. Full ecosystem access — numpy, OpenCV, transformers, anything installed.

py {
    import math
    print("Direct Python:", math.cos(0))

    for i in range(3):
        print(f"Python loop: {i}")
}

Variables share the runtime scope: Origin variables are visible inside py blocks and vice versa. Treat py as trusted code — it executes arbitrary Python.

Binary Builder

Compile scripts to standalone executables with PyInstaller. No Python or Origin needed on the target.

origin build my_robot.or
# my_robot.exe (Windows) / my_robot (Linux/Mac)

Imported .or modules are bundled automatically.

Error Handling

try / except / else recover from runtime errors. else runs only when nothing raised.

Basic Try/Except

try {
    set servo.angle 5, 45
} except {
    print "Servo connection failed"
}

Try/Except/Else

try {
    let val = i2c.read(0x48, 0x01)
    print "Read: " + val
} except {
    print "Hardware read failed"
} else {
    print "Read completed successfully"
}

Friendly Error Messages

# Unknown variable → "I don't recognize 'x'. Did you forget 'let'?"
# Division by zero → "Math Error: You tried to divide by zero!"
# Bad index       → "Range Error: item doesn't exist in that List."
# Type mismatch   → "Type Mismatch: Number vs Text."
# Unknown keyword → caret diagnostic with line:column + suggestion

Exec & Shell

Exec another script

exec "other_script.or"

Spawns a separate process for the target file. Useful for multi-file orchestration.

Run a shell command

run command "echo hello"

Executes via subprocess.run. Same trust rules as py { }.

CLI Reference

origin <file.or>          # run on the bytecode VM (default)
origin i <file.or>        # run on the AST interpreter
origin build <file.or>    # build a standalone binary
origin --version           # print version

Dev runners (from origin-dev/ORIGIN_CODE/runners/): runnerTOML.py <file.or> runs with dialect resolution and --gen rebuilds origin_bytecode.toml; runnerMOD.py, runnerSVM.py, and runnerIR.py cover modular, Rust-bridge, and IR experiments.

Troubleshooting & FAQ

Dialect line runs on VM but not with origin i

Expected — dialects expand only on the VM path. Use origin app.or for dialect programs.

I don't recognize 'x'

You used a variable before let, or inside a function without global. Declare it first or add global x.

Unknown keyword on a line I meant as a dialect

Your origin.toml has no matching mapping (remember matching is per-line and whitespace-normalized). Check the table and keep dialect lines single-line.

Servo doesn't move / clamps unexpectedly

Angles clamp to 0–180° by design. Values outside clamp silently — check your math, then wiring, then Pi permissions for GPIO/I²C.

origin.exe behaves differently from pip runs

The exe falls back to the interpreter (no VM inside). Dialects and strict VM type errors won't reproduce there — verify with pip install origin-or + origin app.or.

How do I add my own shorthand?

Append a line to the installed origin.toml (find it next to the origin package): "my origin code" _ "my shorthand". Use $name for captures.
