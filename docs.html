Language Reference

Origin Documentation

Complete reference for the Origin programming language — hardware-first, expressive, and built for control.

v1.0 v1.5 — current

Variables & Data

Variables in Origin are block-scoped and declared with the let keyword. Use const for values that must not change after assignment — the compiler enforces immutability at runtime.

declaration.org origin 
let   x       = 10
let   name    = "Origin"
const pi      = 3.14159     # immutable — reassignment raises ImmutableError
const MAX_VAL = 255         # convention: ALL_CAPS for module-level constants
INFO Attempting to reassign a const at runtime raises an ImmutableError. See the Error Handling section for recovery patterns.

Control Flow

Origin uses indentation to denote block scope — no braces required. Standard control structures include if / elif / else, while, and for range loops.

control.org origin 
# Conditional
if x > 100
    print "high"
elif x > 50
    print "mid"
else
    print "low"

# Range loop  (start, stop, step)
for i in range 0, 10, 2
    print i

# While loop
let count = 0
while count < 5
    count = count + 1

Functions

Functions are defined with the fn keyword. They are first-class values and can be passed as arguments. Return values are indicated with return.

functions.org origin 
fn add(a, b)
    return a + b

fn greet(name)
    print "Hello, " + name

let result = add 4, 7    # → 11
greet "world"              # → Hello, world

Hardware Control

Low-level hardware interaction is handled through the global set namespace. Commands execute synchronously against the connected device and are available on all supported boards.

servo_sweep.org origin 
# Move servo at index 0 to 90°
set servo.angle 0, 90

# Sweep servo 1 from 0° → 180° in 10° steps
let pos = 0
while pos <= 180
    set servo.angle 1, pos
    pos = pos + 10
Command Parameters Description
set servo.angle (index: int, degrees: float) Moves servo at index to specified angle. Range: 0 – 180°.
set servo.speed (index: int, speed: float) Sets rotation speed for continuous-rotation servos. 0 = stop, ±1 = max.
set pin.high (pin: int) Drives the specified GPIO pin to high (3.3 V) state.
set pin.low (pin: int) Drives the specified GPIO pin to low (0 V) state.
WARN Sending angles outside the 0 – 180° range may damage physical servo hardware. Origin does not clamp values automatically.

Input / Output

Standard output is written with print. User input can be read from stdin using read, which always returns a string — cast explicitly if a numeric value is needed.

io_example.org origin 
print "Enter a number:"
let raw   = read
let value = int(raw)     # explicit cast — raises CastError if non-numeric
print "You entered: " + value

Module System

New in v1.5

Version 1.5 introduced a first-class module system for standard library access and cross-file code reuse. Import an entire namespace or pull named exports directly.

math_example.org origin 
import math

print math.sqrt 16           # → 4.0
print math.pow  2, 8         # → 256.0

# Named import — drops the namespace prefix
from math import sqrt, floor

print sqrt  25               # → 5.0
print floor 3.7              # → 3
INFO Module resolution searches the working directory first, then the standard library path. Third-party packages are not yet supported in v1.5.

Error Handling

Runtime errors are caught with try / catch. The caught object exposes a .type string and a .message string for programmatic inspection.

error_handling.org origin 
try
    const x = 1
    x = 2                    # raises ImmutableError
catch err
    print err.type           # → "ImmutableError"
    print err.message        # → "cannot reassign const 'x'"
Error Type Trigger
ImmutableError Reassignment of a const variable.
CastError Failed type conversion (e.g. int("abc")).
ImportError Module not found during import resolution.
HardwareError Device not connected or set command rejected by board.
