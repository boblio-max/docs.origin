Language Reference

Origin Documentation

Complete reference for the Origin programming language — hardware-first, expressive, and built for control.

v1.5 v1.7 v1.7.5 — Interpreter Stable

Variables & Data

Variables in Origin are block-scoped and declared with the let keyword. All declarations must include an explicit type annotation — the compiler enforces strict typing at runtime.

declaration.org origin 
let   x: int    = 10         # typed declaration
let   name: str = "Origin"
let   flag: bool   = true       # boolean type (lowercase)
const pi: float = 3.14159    # immutable reference
let   empty = none           # none literal
INFO Origin enforces strict typing. Use lowercase true, false, and none for literals. Reassigning a const at runtime will raise a RuntimeError.

Data Structures

Origin supports native lists, dictionaries, and tuples for complex data management.

data.org origin 
# Lists
let my_list: list = [1, 2, 3]
print my_list[0]            # indexing starts at 0

# Dictionaries
let my_dict: dict = {"a": 1, "b": 2}
print my_dict{"a"}           # dictionary access uses { }

# Tuples
let my_tuple: tuple = (10, 20, 30)
print my_tuple[1]

Hardware Control

Safety Updated

Low-level hardware interaction is handled through the global set namespace. Origin provides first-class support for Raspberry Pi GPIO and ServoKit (PCA9685) devices.

hardware.org origin 
# Modern dot-notation
set servo.angle 1, 90       # Set servo 1 to 90 degrees
set pin 12, 1               # BCM pin 12 Output High

# Clamping example
set servo.angle 0, 250      # Automatically clamped to 180
HARDWARE SAFETY Servos now automatically clamp angles to the [0, 180] range to prevent physical damage. A console warning is issued if a value is clamped at runtime.

Module System

v1.7 Logic

The import statement in Origin currently functions as a Header Inclusion mechanism. Importing a file effectively prepends its entire content to the beginning of the current script during processing.

main.org origin 
import more_logic           # Prepends more_logic.or to this file
from math import sqrt       # Direct inclusion from standard libraries

let x: float = sqrt(16)

Raw Python Blocks

New in v1.7.5

Embed raw Python code directly into Origin scripts using the py { ... } syntax. This allows for seamless integration with existing Python libraries.

interop.org origin 
py {
    import math
    for i in range(5):
        print("Python depth:", math.sin(i))
}
