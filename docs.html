Documentation

Complete reference for the Origin programming language v1.7.5.

Variables & Constants

Variables in Origin are block-scoped and declared with the let keyword. All declarations must include an explicit type annotation. Constants use the const keyword and cannot be reassigned.

let   x: int    = 10         # typed declaration
let   name: str = "Origin"
let   flag: bool   = true       # boolean type
const pi: float = 3.14159    # immutable reference

Scope Management

Origin uses robust lexical scoping. Variables declared inside a function are local to that function. To modify a global variable, use the global keyword.

let x = 10

def update() {
    global x
    x = 20  # Modifies global x
}

def local_test() {
    let x = 30 # Local x, doesn't affect global
}

Hardware Control

Origin provides first-class support for robotics hardware. The set namespace handles pins and servos with native safety clamping (0-180°).

set servo.angle 1, 90       # Set servo 1 to 90°
set pin 12, 1               # BCM pin 12 Output High

# Clamping example
set servo.angle 0, 250      # Automatically clamped to 180°

Module System

Origin features a formal module system with clean namespacing. You can import other .or files using import and as.

import math_utils as mu
from hardware import read_sensor

print mu.square(16)
let val = read_sensor(1)

Binary Builder

Origin can compile your scripts into standalone executables that run without needing Python or Origin installed.

# In your terminal:
origin build my_robot.or

# This produces:
my_robot.exe

Raw Python Blocks

Embed raw Python code directly into Origin scripts using the py { ... } syntax for maximum library compatibility.

py {
    import math
    print("Direct math access:", math.cos(0))
}

Error Handling

Use try, except, and else blocks to manage runtime hardware errors gracefully.

try {
    set servo.angle 5, 45
} except {
    print "Servo connection failed"
}
