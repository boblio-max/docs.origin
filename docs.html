Language Reference

Origin Documentation

Complete reference for the Origin programming language — hardware-first, expressive, and built for control.

v1.5 v1.7 — current

Variables & Data

Variables in Origin are block-scoped and declared with the let keyword. All declarations must include an explicit type annotation — the compiler enforces strict typing and immutability (for const) at runtime.

declaration.org origin 
let   x: int    = 10         # typed declaration
let   name: str = "Origin"
let   flag: bool   = True       # boolean type
const pi: float = 3.14159    # immutable — reassignment raises RuntimeError
INFO Attempting to reassign a const at runtime raises an ImmutableError. See the Error Handling section for recovery patterns.

Data Structures

Origin supports native lists and dictionaries for complex data management. Lists are ordered sequences, while dictionaries map keys to values.

data.org origin 
# Lists
let my_list: list = [1, 2, 3]
print my_list[0]            # indexing starts at 0

# Dictionaries
let my_dict: dict = {"a": 1, "b": 2}
print my_dict{"a"}           # dictionary access uses { }

print len(my_list)           # returns collection length

Control Flow

Origin uses indentation to denote block scope — no braces required. Standard control structures include if / elif / else, while, and for range loops.

control.org origin 
# Conditional
if x > 100 {
    print "high"
} elif x > 50 {
    print "mid"
} else {
    print "low"
}

# Range loop
for i in range(0, 10) {
    print i
}

# While loop
let count: int = 0
while count < 5 {
    count = count + 1
}

Functions

Functions are defined with the def keyword. They are first-class values and can be passed as arguments. Return values are indicated with return.

functions.org origin 
def add(a, b) {
    return a + b
}

def greet(name) {
    print "Hello, " + name
}

let result: int = add(4, 7)    # → 11
greet("world")              # → Hello, world

Hardware Control

Low-level hardware interaction is handled through the global set namespace. Commands execute synchronously against the connected device and are available on all supported boards.

servo_sweep.org origin 
# Move servo at index 0 to 90°
set servo[0] = angle, 90

# Sweep servo 1 from 0° → 180° in 10° steps
let pos: int = 0
while pos <= 180 {
    set servo[1] = angle, pos
    pos = pos + 10
}
Command Parameters Description
set servo[index] = angle, val (index: int, val: int/float) Moves servo at index to specified angle. Range: 0 – 180°.
set pin[pin] = state, val (pin: int, val: int) Drives specified GPIO pin (1 for High, 0 for Low).
WARN Sending angles outside the 0 – 180° range may damage physical servo hardware. Origin does not clamp values automatically.

Input / Output

Standard output is written with print. User input can be read from stdin using input(), which always returns a string — cast explicitly if a numeric value is needed.

io_example.org origin 
print "Enter a number:"
let val: str = input("> ")
let x: int   = int(val)     # explicit cast
print x

Module System

New in v1.5

Version 1.5 introduced a first-class module system for standard library access and cross-file code reuse. Import an entire namespace or pull named exports directly.

math_example.org origin 
import math
import random

print math.sqrt 16           # → 4.0
print math.pow  2, 8         # → 256.0
print random.randint(1, 10)    # → random integer

# Named import — drops the namespace prefix
from math import sqrt, floor

print sqrt  25               # → 5.0
print floor 3.7              # → 3
INFO Module resolution searches the working directory first, then the standard library path. Third-party packages are not yet supported in v1.5.

File I/O

New in v1.7

Read from and write to standard files directly using the open statement. File modes include "r", "w", "a", etc. mapping straight to python built-ins via the compiler layer.

files.org origin 
open "data.txt" "w" as f
# further write operations ...

Object-Oriented Programming

New in v1.7

Origin now includes a structured class keyword. Classes bundle fields natively, offering methods inside class blocks directly executed as blocks mapping methods internally.

class_example.org origin 
class Robot(name, id) {
    def identify() {
        print "I am a robot"
    }
}

Concurrency

New in v1.7

Perform multi-processor parallel tasks syntactically using the parallel block to scale computations across system threads dynamically natively.

parallel.org origin 
parallel (4) {
    # Task runs across 4 threads
    print "Working concurrently"
}

Math & System Execution

New in v1.7

A host of new mathematical built-ins as well as inline code execution pipelines have been provided natively directly connected to the system core interpreter layer.

math_sys.org origin 
let x: float = sqrt(25)               # → 5.0
let rnd: int = rand_num(1, 10)      # → 1-10 inclusive
let sz: int  = len([1, 2, 3])       # → 3

exec "print('hello from subprocess')"

Advanced Types (Structs, Enums, Interfaces)

New in v1.8

Origin now offers robust low-level type definitions including struct, enum, and interface to structure highly organized, memory-efficient data payloads natively.

types.org origin 
struct Vector3 {
    x: float
    y: float
    z: float
}

enum Direction {
    UP, DOWN, LEFT, RIGHT
}

interface Renderable {
    def draw()
}

Pattern Matching & Advanced Control

New in v1.8

Replace deep if / elif chains with expressive match / case blocks. We also added new control structures like until, loop, and unless.

matching.org origin 
match dir {
    case Direction.UP {
        print "Moving sequence up"
    }
    case Direction.DOWN {
        print "Moving sequence down"
    }
}

unless disabled {
    print "Executing because not disabled"
}

Async/Await & Macros

New in v1.8

Support for true asynchronous execution loops natively bound to the event-loop via async and await keywords, plus AST-level metaprogramming through macro definitions.

async.org origin 
async def fetch_data() {
    let result = await network_call()
    return result
}

macro debug_print(val) {
    # Will compile inline as heavily optimized output
    print "DEBUG: " + val
}

Error Handling

Runtime errors are caught with try / catch. The caught object exposes a .type string and a .message string for programmatic inspection.

error_handling.org origin 
try {
    let x: int = 1
    x = "error"               # raises TypeError
} except {
    print "Caught type mismatch"
} else {
    print "No error"
}
Error Type Trigger
TypeError Type mismatch in variable assignment or operation.
RuntimeError Generic execution error (e.g. constant re-assignment).
NameError Variable or function not found in current scope.
SyntaxError Illegal character or malformed code structure.
