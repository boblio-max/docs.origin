Legacy Versions

Access previous stable releases of the Origin toolchain. We recommend using the latest version for the best experience.

v1.7.15 Latest

Released July 31, 2026
Adds typed parameters and typed class fields (def add(a: int, b: int), class Point(x: int, y: int)), typed loop variables and condition casts, type-aware casts on builtin arguments (len(x: str), sqrt(x: float), rand_num(1: int, 100: int), range(0: int, 10: int, 2: int)), auto-inference for untyped let/const declarations with a warning nudge, a range(start, end, step) step argument, and stricter const immutability in both the VM and interpreter.

v1.7.14 Stable

Released July 30, 2026
Adds NN library for fine-tuning transformer models from pure Origin code. Includes transformer.or wrapper with LoRA support, bytecode VM fixes (function scope chaining, .or import inlining, premature HALT fix), scientific notation, none literal, global variable scoping fixes, and write/append node fixes.

v1.7.13 Stable

Released July 30, 2026
Initial NN library release with bytecode VM fixes. Includes transformer.or wrapper with LoRA support, function scope chaining, .or import inlining, and premature HALT fix.

v1.7.11 Stable

Released July 3, 2026
Adds native IMU sensor support — declare mpu6050 address 0x68 and read accel, gyro, and temp directly. Includes interpreter mode (origin i file.or) alongside the VM backend.
